Governance-as-Code Accelerator — Maturity Assessment Instrument

Self-contained, offline, deterministic scoring tool. No network calls, no external dependencies — open this file directly in any browser.

Purpose & how to use it

Converts the source strategy report's telemetry/KPI matrix (COV, VPL, ARI, PDR, QVD, CC, APF, EAR, OCI, DOR, SMC, SDDR) into a scored, repeatable questionnaire. This is a deterministic instrument: the same answers always produce the same overall score and Wave recommendation, regardless of which consultant runs it.

  1. For each of the 16 questions below, pick a score from 0 (not in place / worst case) to 5 (fully mature / best case). All scores start at 0 so the page opens with a valid, error-free Wave 1 result — overwrite every row with the client's real answers before trusting the Results section.
  2. Dimension subtotals, weighted contribution, and the overall score are computed automatically as you score — nothing to calculate by hand.
  3. The overall score is looked up against the Wave Thresholds table to recommend which of the 90-Day Roadmap's three Waves the client should start in.
  4. Set a Target score (0–100) per dimension in the Results section (defaults to 70 — the Wave 3 threshold — as a "fully automated" aspiration; recalibrate per client). The Maturity Wheel plots Current vs. Target as a radar chart for live use in the workshop, alongside a representative activity per dimension to anchor the discussion.
  5. Your answers are saved to this browser's local storage automatically (not sent anywhere) so you can close and reopen the file without losing progress on the same machine. Use Print / Save PDF or Copy results summary to hand off results elsewhere.

Scope note

Dimension weights (25% each by default) and the Wave thresholds (40 / 70) are starting defaults calibrated against the illustrative client in the source report, not an empirically derived industry standard — recalibrate them per client/industry if you have a better basis, and treat recalibration as a deliberate decision, not a silent edit.
